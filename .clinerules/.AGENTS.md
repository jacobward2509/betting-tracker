NEVER pipe command output through `| tail`, `| head`, `2>&1 |`, or any other shell redirection/piping when running commands (e.g. Playwright test runs). Run the command directly, exactly as a user would type it, with no piping or redirection whatsoever.

NEVER use Python (or any other scripting language run via a shell command, e.g. `python3 - <<EOF ... EOF`, `node -e`, `perl -i`, `sed`/`awk` one-liners, heredocs, etc.) to create, edit, or patch files. This applies unconditionally, in every mode, including when making "quick" or "simple" refactors. All file creation and editing MUST go through the dedicated file-editing tool only. The terminal/command-runner tool is exclusively for running real commands a user would type (builds, tests, git, package managers, etc.) — never for writing or modifying source code, config, or any other file content.

NEVER take an implementation action — editing files, running state-changing commands, or otherwise executing a task — while in plan mode. Plan mode is for exploring, reading, and proposing a plan only. Wait for an explicit switch to act mode before making any changes.
